Mother's Day Website — How to fill in your details
====================================================

This is a demo page. Everything in [square brackets] is a placeholder.
Replace those with your own words. You do not need to know coding —
just open the files in any text editor (Notepad on Windows, TextEdit
on Mac) and change the bracket text.

WHERE THE FILES ARE
-------------------
index.html   — the main page (open this in a browser to view the site)
styles.css   — the look and colors (you usually don't need to touch this)
script.js    — the animations (you usually don't need to touch this)
images/      — the 6 photo files used in the gallery
README.txt   — this guide


1. MOM'S NAME — DONE
--------------------
Mom's name is set to Maya in the page title, hero headline, and letter greeting.
No need to change this unless you want a different name.


2. YOUR NAME
------------
Find and replace every:
  [Your name]
with your name.

Places it appears:
  - The end of the letter ("With love, [Your name]")
  - The footer ("Made with love by [Your name]")


3. YOUR MESSAGE (THE LETTER)
----------------------------
Find:
  [Write your message to Mom here]
and
  [Add another paragraph if you want — tell her why she means so much to you]

Replace those with your own words. You can keep one paragraph or write more.


4. REASONS I LOVE YOU (6 cards)
-------------------------------
Find each of these and replace with a short reason:
  [Reason 1 — e.g. your kindness, your cooking, how you always listen…]
  [Reason 2]
  [Reason 3]
  [Reason 4]
  [Reason 5]
  [Reason 6]

You can also change the little titles "Reason 1", "Reason 2", etc.
to short labels if you want (like "Your cooking" or "Your hugs").
The emoji icons can be changed too — just swap the emoji character.


5. PHOTO GALLERY (6 photos)
---------------------------
The demo uses placeholder pictures in the images folder.

To use your own photos:
  1. Get 6 photos of your mom / family.
  2. Rename them exactly like this and put them in the images/ folder,
     replacing the demo files:
       photo1.jpg
       photo2.jpg
       photo3.jpg
       photo4.jpg
       photo5.jpg
       photo6.jpg
  3. In index.html, find each [Photo caption 1] through [Photo caption 6]
     and write a short caption for that photo.

Tip: JPG or PNG both work. Keep the same file names so you don't have
to change anything else.


6. MEMORY TIMELINE (4 entries)
------------------------------
For each entry, replace:
  [Year]            → a year or date (e.g. 2018, or "Summer 2020")
  [A favorite memory] / [A favorite memory — e.g. that trip we took together…]
                    → a short memory sentence


HOW TO VIEW THE SITE
--------------------
Double-click index.html — it will open in your web browser.
Or right-click → Open with → Chrome / Safari / Edge / Firefox.


THAT'S IT!
----------
Change only the [bracket] text and the photos. The rest of the site
(colors, layout, animations) already works.

Name is set to Maya (placeholder [Mom's name] replaced).
